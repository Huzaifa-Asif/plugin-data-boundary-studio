# Privacy

Plugin Data Boundary Studio processes entered descriptions and imported JSON in the browser. It does not send those contents to the maintainer, use analytics, create accounts, set cookies, or load third-party code.

Do not enter real records, credentials, tokens, identifiers, or sensitive values. Describe data elements and categories only. Clear, sample replacement, and successful import retain one in-memory undo copy for ten seconds. Closing or reloading the page clears unsaved inventory. Theme preference is stored in browser local storage.

Downloaded JSON and Markdown files are created locally by the browser and remain under the user's control. GitHub Pages receives ordinary web request metadata under GitHub's own policies. Repository issues and contributions are public unless GitHub labels them otherwise.

This document describes this tool, not a plugin assessed with it. It is not a generated privacy policy for another product.
