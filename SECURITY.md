# Security

## Supported version

Security fixes are applied to the latest release.

## Reporting

Use GitHub's private vulnerability reporting for the repository. Do not open a public issue containing a vulnerability, credential, access token, personal record, or production data. If private reporting is unavailable, open a content-free issue asking the maintainer to enable a secure reporting channel.

## Scope

The hosted application is static and has no account or backend. The local server is for development only and is intentionally loopback-only. Reports about credential detection bypasses, unsafe rendering, import denial of service, host validation, security headers, and unexpected network behavior are in scope.
